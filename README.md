# 한부모가족 온(ON) — 정책연구용 통합지원 플랫폼 MVP

## 포함 파일
- `index.html`: 프레임워크/빌드 없이 바로 실행 가능한 반응형 시민·관리자 웹 대시보드
- `server.mjs`: Node.js 20 이상 정적서버 및 선택형 AI 상담 API 프록시
- `README.md`: 실행·배포·실서비스 전환 안내서

## 즉시 실행
1. `index.html`을 브라우저에서 열면 대부분의 시연 기능이 작동합니다.
2. 서버 실행 권장: Node.js 20 이상 설치 후 이 폴더에서 `node server.mjs` 실행
3. 브라우저에서 http://localhost:3000 열기
4. API 키 없이도 상담원은 로컬 규칙형 안내로 동작합니다.

## AI 모델 연동(선택)
API 키를 브라우저에 넣지 마세요. `server.mjs`는 서버 환경변수의 키로 AI API 호출을 수행합니다.
- Windows PowerShell: `$env:OPENAI_API_KEY="YOUR_KEY"; node server.mjs`
- Linux/macOS: `OPENAI_API_KEY="YOUR_KEY" node server.mjs`
- 선택 모델: `OPENAI_MODEL` 환경변수 (기본값 gpt-4.1-mini, 이용 가능 여부 확인)
- 실제 운영에는 API 비용통제, 레이트리밋, 인증, 상담로그 관리, 최신 공식근거 문서 검색(RAG), 민감정보 차단, 법령 버전 관리 필요

## 정적 배포 (빠른 데모)
- GitHub Pages / Netlify / Cloudflare Pages에 `index.html`만 업로드하면 정적 데모가 동작합니다.
- 이때 `/api/chat` 엔드포인트가 없어 기본 규칙형 상담으로 자동 전환됩니다.
- Node.js 서버와 AI 연동을 함께 배포하려면 Render/Railway/가상서버 등 Node 실행환경에 이 폴더를 배포하고 실행명령 `node server.mjs`를 등록하세요. (호스팅별 설정과 공개접근 제어 필요)
- 공공기관의 실환경 서비스라면 공공클라우드·보안요건·개인정보 영향평가 해당 여부 등 별도 검토 필요

## 기능
- 현행 2026 소득인정액 기준 참고 비교(2~6인, 일반/청소년 한부모)
- 2024~2026 연간 근로소득 → 3년 평균 월소득 산출 및 경계가구 개선안 비교
- 신청 접수·심사·지급 5단계 시연(실제 신청 및 지급 아님)
- 돌봄/교육/심리/생활 연계 프로그램 소개와 연계 희망 등록
- 가족 구성원별 만족도 설문과 가상 집계
- 정책수혜율·지원 사각지대·90%/100% 목표 모니터링, CSV 내보내기
- 공식 공공서비스 링크 및 상담

## 보안/데이터 유의사항
- 입력 내용은 동일 브라우저의 `localStorage`에 저장됩니다. 여러 기기에 동기화하지 않습니다.
- 실명, 주민등록번호, 실제 소득, 건강정보, 아동 개인정보 등 실제 개인정보는 입력하지 마세요.
- 초기 수혜가구(7,840/10,000), 만족도 등은 **가상 예시**입니다. 실측 통계가 아닙니다.
- 실제 공공기관 인증/신청/지급/민원처리/국세청 조회/법령 API는 **연계되지 않았습니다**.
- 소득금액 3년 평균으로 현행 자격을 확정하지 않습니다. 3년 평균 심사는 정책개선 대안이며 법적 채택 여부 미정입니다.
- 비현금 서비스를 모든 한부모가족에 제공하는 것은 제안입니다. 운영기관의 개별 자격·자원 제약은 그대로 존재합니다.

## 실서비스 전환 구성안
1. 본인확인/역할별 인증(보호자, 성년 자녀, 청소년 접근 권한, 지자체 담당자)
2. 한부모가족지원법 및 관련 고시 버전형 룰엔진 + 실무자 검수 + 변경관리
3. 관계기관의 법률적 근거/협약을 확보한 후 정부24/복지로/사회보장정보시스템/국세청(공공 마이데이터 등 승인된 경로) 연계
4. 3년 소득의 누락연도, 휴·폐업, 근로/사업/기타소득, 재산환산, 소득조정, 급격한 변동까지 처리; 법정 심사와 정책대안 병렬 비교
5. 신청·처리·이의신청·결정·지급원장 DB 구축; 기관에서 회신된 상태에 대해서만 확정 표기
6. 비현금 서비스 사업자별 자격/정원/예약/연계결과 API 연계, 비보편 지원과 신규 보편 시범사업의 분리
7. 가구 중복 제거 및 적격 모집단 추계, 지역/연령/가족유형별 수혜율, 신청포기율, 처리기간, 불만족 개선조치 등 KPI
8. 동의/목적제한/최소수집/암호화/권한분리/감사로그/보존기간/삭제정책, 개인정보 보호법·아동보호 검토
9. AI RAG 근거제시 및 문서 최신성 확인; 챗봇의 비결정적 답변으로 수급·민원 결과 결정 금지
10. 접근성(KWCAG), 모바일/저대역폭, 다국어, 음성 안내, 민원 안내·전화/방문 대체 채널 확보

## 정책성과 지표 정의 제안
- 실제 수혜율 = 기간 내 적격 집단 중 1개 이상 현금 또는 비현금 서비스를 실제 제공받은 **고유 가구 수** / 같은 기간 전체 적격 가구 수 × 100
- 정보 도달률 = 정책안내를 확인한 적격 가구 수 / 전체 적격 가구 수 × 100
- 신청 완료율 = 유효 신청 완료 가구 수 / 신청 개시 가구 수 × 100
- 서비스 연결 성공률 = 실제 제공 완료 건수 / 연계 요청 건수 × 100
- 만족도 = 구성원·연령별 표본 설계 및 응답편향 교정 후 5점 평균, 동시에 저만족 비중 추적
- 취약집단 격차 = 유형/지역별 수혜율 차이와 미연결 사유. '최종 100%'는 모든 대상이 인지·접근·선택할 수 있는 보편적 접근을 의미하도록 정책적으로 정의 검토 필요
